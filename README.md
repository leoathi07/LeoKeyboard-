# LeoKeyboard

Smart Typing. Smarter You.

An Android keyboard application by LeoTechWorld.

## Features
- AI Smart Replies
- Grammar Correction
- Auto-Correction ON/OFF
- 20 Keyboard Themes
- Emoji, GIF and Stickers
- Voice Typing
- Clipboard History
- Personal Photo Keyboard
